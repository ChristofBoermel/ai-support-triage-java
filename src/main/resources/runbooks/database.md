# Database runbook

- Confirm database availability, connectivity, and current service health.
- Review application logs for connection-pool exhaustion, query timeouts, or authentication failures.
- Check recent migrations for failures, locks, schema mismatches, or long-running operations.
- Review database capacity indicators, including connection count, storage, CPU, and replication health.
- Identify whether the issue affects reads, writes, or a specific query path before taking corrective action.
